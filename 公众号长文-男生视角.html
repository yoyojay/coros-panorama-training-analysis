我替你问了问这位啃高驰数据的杭州狠人

受访者 @ycz · 浙江杭州 · 跑者 / 训练分析技能作者

我是小悠。最近 YOJO 训练室来了一位杭州的跑者 @ycz，做了个超硬核的高驰训练分析技能，报告做得我自己都挪不开眼。我拉着他聊了一轮，把干货和几张报告都搬出来给你看。

月度总览 距离 236.41km 配速 6'05" VO2max 51 全摆在一张图上

小悠

你为啥要自己搞这么个技能，市面上的跑步 App 不够用吗？

@ycz

受够了那些甩一句你配速退步了的 App。我把高驰账号接上，自己跑去把活动、逐公里明细、心率、恢复、负荷全拉下来，再叠一层当天真实天气，最后吐出一份能直接打开看的 HTML 报告。

小悠

第一版出来你啥反应？

@ycz

手机没放下过。像素风，青柠绿配墨绿底，数据铺得满满当当，我存下来当了壁纸。

这个技能是什么

@ycz 来自浙江杭州。他做了个基于高驰数据的全景训练分析技能包。既能当 Agent 的 Skill 直接调，也能当纯 Python 脚本独立跑。零 MCP 依赖，装一个 httpx 就行。最爽的是不用自己拼表，只管跑，报告自己长出来。

我翻他报告翻出三件最较真的事，他管这叫三板斧。

16.66km LSD 心率 6 区分布 逐公里配速柱 训练负荷一目了然

48 分钟力量训练 胸背肩腿核心组数拆解 42 组时间线

小悠挖出的三板斧

第一斧 把天气当刚需

小悠观察

33°C 那天配速比平时慢 20 秒，他不会甩你一句退步了。他明明白白写，正常，热应激。

@ycz 补一句

多少人把天热跑不动误判成自己菜，我偏不。

第二斧 热适应真懂行

小悠观察

湿球、澳式体感、估算 WBGT 全给你算上，还跨天比同配速心率变没变。

@ycz 补一句

我最爱看那句，同配速心率下来了，你耐热了。像真有人在陪你变强。

第三斧 负荷和就绪度够狠

小悠观察

ACWR、Form、每天 0 到 100 分就绪度。高负荷又低就绪度，他直接劝你减量。

@ycz 补一句

等于旁边坐着个不敢让你乱来的教练。

17k EasyRun 每公里配速按 Easy Threshold Recovery 三色着色

18K EasyRun 配速公里柱状图 Threshold 区间虚线标注

5 月月报 西湖路线地图 恢复负荷 VO2max 全马预测 3:36:07

小悠的总结

这不是又一个帮你看看数据的玩具。是个真把跑者较真数据当回事的技能，杭州的 @ycz 做的。开源在那儿，想 self-host 自己跑报告的，去把玩。
